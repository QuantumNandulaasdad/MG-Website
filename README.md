# Signal story of Myasthenia Gravis

Educational article by Kaushik, created with AI assistance. Includes two licensed
scientific figures, an original body map, a phone analogy and the existing MG game link.

## GitHub Pages
Upload the contents of `dist/` to the root of the existing MG-Website repository:
index.html, styles.css, app.js, .nojekyll, IMAGE-CREDITS.txt and the assets folder.
Keep the assets folder structure. No build step is needed.
The GitHub download archive has these files already at its root.

## Images
See dist/IMAGE-CREDITS.txt for complete attribution and reuse terms.
Figures 1 and 2 are from Kaminski et al. (2024), JCI, CC BY 4.0.
All images are bundled locally, so the website does not depend on image hotlinks.
The image viewer supports keyboard operation and ordinary image links without JS.

No third-party scripts, fonts, analytics or data collection are used.
