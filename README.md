# Signal Story — Myasthenia gravis, explained

An illustrated article by Kaushik for a general audience, with a focus on women aged 20–40 in Singapore. The page includes normal transmission, AChR-antibody MG mechanisms, a written phone analogy, a comparison toggle, symptoms, care and linked references. The final button opens the supplied game at https://quantumnandulaasdad.github.io/Mg-Game/.

The age section cites SingHealth and MedlinePlus public clinical summaries. Their “women under 40” statements are not represented as Singapore registry counts or an exact risk estimate for ages 20–40.

## Files
- `dist/index.html`: article and original illustrations.
- `dist/styles.css`: responsive editorial design.
- `dist/app.js`: optional comparison, reading navigation and progress.

No third-party runtime libraries, fonts, analytics or data collection. The article and game link work without JavaScript; the comparison control requires it. Source content checked 25 October 2026. Created with AI assistance.

## Static hosting
Upload the contents of `dist/` to a static host. For GitHub Pages, put `index.html`, `styles.css` and `app.js` at the publishing root. Keep the filenames together.
