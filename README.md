# Signal story of Myasthenia Gravis

Educational article by NV Kaushik, created with AI assistance. Includes two licensed
scientific figures, an original body map, a phone analogy and the existing MG game link.

index.html, styles.css, app.js, community.js, comments-config.html, .nojekyll, IMAGE-CREDITS.txt and the assets folder.

## Community features
The article has a Giscus discussion below the game invitation. The game links back to this single thread. Readers can view comments without signing in; posting requires GitHub authentication. The supplied comments-config.html already includes the owner-provided repository and category IDs. Keep Discussions enabled and the Giscus app installed for the existing public MG-Website repository. No code editing is needed before uploading. Only the public article loads the configured widget, after the reader selects Show comments. The config file contains public identifiers only. See COMMUNITY-SETUP.txt.

There is no visitor counter or analytics script. The article and game work independently of comments. The configured widget uses the purple_dark theme, a bottom comment box, and the supplied specific-term mapping. Private previews do not load a live discussion. No START-HERE generator or root verification homepage is required.
